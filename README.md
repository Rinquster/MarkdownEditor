# MDEditor

Локальный редактор и просмотрщик серий Markdown-файлов. Статическое приложение без сборки — подходит для хостинга на GitHub Pages.

## Возможности

- **Сайдбар с файлами**: drag-n-drop загрузка файлов и целых папок (вложенность разворачивается в плоский список), создание, переименование, дублирование, скачивание и удаление через меню «⋯». Ширина сайдбара регулируется перетаскиванием правого края (двойной клик — сброс).
- **Глобальный режим Просмотр/Редактор** в шапке — держится при переключении между файлами, пока вы сами его не смените.
- **Настройки просмотра**: гарнитура (Lato по умолчанию, Inter, Roboto, Whitney, Antiqua, Liberation Sans/Serif) и размер базового текста — заголовки и остальные элементы масштабируются от него.
- **Размер шрифта редактора** (моноширинный Source Code Pro).
- **Скачивание всех файлов одним ZIP** кнопкой в шапке.
- **Справка-приветствие** живёт в отдельном «призрачном» разделе над списком файлов: не мешает работе, не попадает в ZIP, удаляется насовсем вместе со своим разделом.
- Все файлы и настройки сохраняются в браузере (IndexedDB + localStorage): автосохранение при правках, немедленное сохранение структурных операций и аварийный снимок при закрытии вкладки.

## Структура

```
index.html        — разметка
css/style.css     — цветовые токены, layout, типографика превью
js/app.js         — вся логика (vanilla JS, IIFE)
vendor/           — marked 12.0.2, JSZip 3.10.1
fonts/            — самостоятельно хостимые woff2
```

## Деплой

Любой статический хостинг: пути относительные, сборка не нужна. Для GitHub Pages достаточно включить Pages на ветке с этими файлами.
