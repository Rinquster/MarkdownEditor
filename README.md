# MarkdownEditor

Локальный редактор и просмотрщик серий Markdown-файлов. Статическое приложение без сборки — подходит для хостинга на GitHub Pages.

## Возможности

- **Дерево файлов и папок**: drag-n-drop загрузка файлов и целых папок с сохранением структуры (пустые каталоги тоже переносятся), создание, переименование, дублирование, скачивание и удаление через меню «⋯». Файлы и папки перетаскиваются между папками прямо в списке. Ширина сайдбара регулируется перетаскиванием правого края (двойной клик — сброс).
- **Поиск по файлам и тексту**: одно поле над списком фильтрует дерево по именам, путям и содержимому; у файлов с совпадениями в тексте показано их число.
- **Поиск внутри документа** по Ctrl+F — работает и в превью, и в редакторе, с переходом по совпадениям и счётчиком.
- **Оглавление** отдельной колонкой справа (кнопка в шапке): заголовки получают якоря, клик по пункту подводит раздел к верху.
- **Отмена удаления**: после удаления файла, папки или справки в статусной строке двенадцать секунд висит кнопка «Отменить» — возвращается всё вместе с вложенностью.
- **«Удалить всё»** — кнопка в шапке панели: убирает все файлы и папки разом (справка остаётся, у неё своё удаление). Отменяется так же, как обычное удаление.
- **Три режима в шапке — Просмотр, Вместе, Редактор.** Выбранный держится при переключении между файлами, пока вы сами его не смените.
- **Режим «Вместе»**: исходник слева, результат справа, делитель тянется мышью (двойной клик — поровну). Прокрутка панелей связана **по строкам разметки**, а не по процентам, поэтому длинные блоки кода не разводят панели; правки видны в превью сразу.
- **Настройки просмотра**: гарнитура (Lato по умолчанию, Inter, Roboto, Liberation Sans, Liberation Serif) и размер базового текста — заголовки и остальные элементы масштабируются от него.
- **Размер шрифта редактора** (моноширинный Source Code Pro).
- **Правка текста**: Ctrl+B, Ctrl+I, Ctrl+` и Ctrl+K, панель форматирования над редактором (сворачивается). Enter продолжает списки, нумерацию, пункты задач и цитаты, Tab и Shift+Tab сдвигают выделенный блок. Родная отмена (Ctrl+Z) при этом работает.
- **Подсветка разметки в редакторе**: заголовки, списки, цитаты, ссылки, блоки кода и таблицы видны прямо при письме. Выключается кнопкой-палитрой в панели форматирования.
- **Подсветка кода** в блоках превью: JavaScript/TypeScript, JSON, Python, Bash, HTML/XML, CSS, SQL. Без внешних библиотек, корректно работает с нелатинскими именами.
- **Копирование**: кнопка на каждом блоке кода в превью и кнопка «Текст» в шапке — весь документ голым текстом, без разметки.
- **Скачивание в ZIP**: всё дерево кнопкой в шапке или отдельная папка через её меню; структура каталогов сохраняется.
- **Справка-приветствие** живёт в отдельном «призрачном» разделе над списком файлов: не мешает работе, не попадает в ZIP, удаляется насовсем вместе со своим разделом.
- **Безопасный просмотр**: HTML из документа чистится по белому списку — обработчики событий, `javascript:`-ссылки и посторонние теги до страницы не доходят.
- **Работа в нескольких вкладках**: изменения из соседней вкладки подхватываются автоматически; текст, который вы правите прямо сейчас, не подменяется.

- **Светлая и тёмная темы** — кнопка в шапке перебирает «как в системе», светлую и тёмную.
- **Сведения о документе** в шапке: путь, состояние сохранения, число слов и время чтения.
- **Печать** по Ctrl+P — на бумагу идёт только текст документа — и **экспорт в HTML**: самодостаточная страница со своим стилем и подсветкой.
- **Мобильный режим**: на узком экране панель файлов выдвижная.
- **Клавиатура**: стрелки по дереву файлов и по контекстному меню, ширина панели меняется стрелками, фокус заперт в диалоге.

## Шрифты

Все гарнитуры свободные: Lato, Inter и Source Code Pro под SIL OFL 1.1, Roboto под Apache 2.0,
Liberation Sans/Serif под GPL со шрифтовым исключением. Условия сведены в
[fonts/LICENSES.md](fonts/LICENSES.md) — OFL и GPL требуют прикладывать их при распространении.

Файлы урезаны до нужных проекту диапазонов символов (латиница, кириллица, греческий,
типографика, стрелки, математика, псевдографика): это вдвое сокращает первую загрузку.

## Хранение

Всё лежит в браузере и никуда не отправляется.

- **IndexedDB** (`mdeditor`, версия базы 2): store `files` — по записи на файл, store `meta` — дерево папок, справка, раскрытые узлы и текущий файл. Пишется только изменившееся.
- **localStorage**: настройки интерфейса и аварийный снимок открытого файла на случай, если вкладку закрыли между автосохранениями.

Данные из прежних версий поднимаются автоматически: миграции v1→v3 и v2→v3 работают при первом запуске.

## Структура

```
index.html        — разметка
css/style.css     — цветовые токены, layout, типографика превью
js/app.js         — вся логика (vanilla JS, IIFE)
vendor/           — marked 12.0.2, JSZip 3.10.1
fonts/            — самостоятельно хостимые woff2 (урезанные; лицензии в fonts/LICENSES.md)
tools/            — вспомогательные скрипты (пересборка шрифтов)
tests/            — страницы-проверки и их раннер (см. tests/README.md)
```

## Тесты

```
node tests/run.js
```

Раннер сам поднимает локальный сервер и headless-браузер: 15 страниц, 448 проверок.
`node tests/coverage.js` показывает, что из `js/app.js` тесты ни разу не выполнили.
Подробности — в [tests/README.md](tests/README.md).

## Деплой

Любой статический хостинг: пути относительные, сборка не нужна. Для сайта достаточно `index.html`, `css/`, `js/`, `vendor/` и `fonts/` — `tools/` и `tests/` выкладывать незачем. Упаковщик архивов подгружается только при обращении к ZIP, шрифт интерфейса системный — первая загрузка не тянет ничего лишнего. Для GitHub Pages достаточно включить Pages на ветке с этими файлами. Каталог `tests/` на работу приложения не влияет и при желании выкладывается или нет.
